# Summary

Ghostty is organized around a large Zig **src/** core that implements terminal behavior, CLI actions, shell integration, an optional inspector, and a GTK application port, while **macos/** hosts the primary SwiftUI native shell. The public story in seeds emphasizes shipping both a full emulator and **libghostty-vt** for embedders, with many **example/** projects documenting the C/Zig API. **AGENTS.md** names the everyday agent workflow: **zig build**, filtered **zig build test**, and separate paths for VT library work, macOS **build.nu**, and release benchmarks.

Observations:

- Seeds are dominated by **example/** READMEs; top-level **README.md** and **AGENTS.md** carry most of the architectural narrative.
- macOS and Zig core are explicitly split: library updates via **zig build**, app via **macos/build.nu**.
- Roadmap item still open in README: Ghostty-only control sequences (everything else marked done in the table).
