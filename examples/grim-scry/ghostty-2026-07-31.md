# Summary

Ghostty is a shipping terminal product and a library platform. The Zig tree under `src/` owns emulation, CLI, shell integration, and GTK; `macos/` is the SwiftUI shell. `example/` is a large matrix of libghostty consumers. `AGENTS.md` is the agent entry point for build, test, and layout; nested `AGENTS.md` files mark subsystem boundaries (terminal, font, fuzz, inspector).

Observations:

- **Dual product**: end-user terminal plus **libghostty-vt** as a first-class embeddable API - `example/` is the public integration surface, not demo fluff.
- **Zig-centric workflow**: `zig build` / `zig build test` everywhere; macOS app is a separate tree; agents are told to use test filters because the full suite is slow.
- **No ADR seeds** in discover output - architecture lives in README, `AGENTS.md`, and nested agent guides rather than `docs/adrs/`.
