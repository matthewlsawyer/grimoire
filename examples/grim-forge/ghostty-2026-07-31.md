## HISTORY.md

```markdown
# History

Ghostty is a fast, native, feature-rich terminal emulator written primarily in Zig, with macOS (SwiftUI/AppKit) and Linux/FreeBSD (GTK) applications and an embeddable `libghostty` / `libghostty-vt` library. This ledger records the project's story arc — origins, turning points, and eras — distinct from release notes or changelogs.

## Story

A solo Zig experiment in 2022 became a cross-platform terminal used by millions daily, then began exporting its core as `libghostty-vt` for embedders while continuing to chase performance and platform-native polish.

### Origins

Mitchell Hashimoto started Ghostty in March 2022 to break the speed / features / native-UI tradeoff common among terminal emulators. Early work was rendering infrastructure — OpenGL abstractions, a pure-Zig font atlas, windowing — but by April 2022 a basic VT parser, PTY attachment, and terminal-to-GPU text pipeline existed. The architectural commitments formed quickly: multi-threaded I/O (read, write, and render threads), a heavily optimized stream parser, and platform-native renderers (Metal on macOS, OpenGL on Linux). macOS tabbing and a Metal renderer landed by late 2022; release automation and signed macOS bundles followed in November.

## 2026-07-30

Post-1.3 development concentrates on memory efficiency, embedder APIs, and platform breadth. Scrollback gains configurable line and byte limits, optional unlimited mode, and LZ4-based cold-history page compression exposed through `libghostty-vt`. A broad `SelectionGesture` API lands in the C library. `PageList` grows builder/allocation APIs for raw-page construction. Zig 0.16 migration completes (May → July). Windows static linking for `libghostty-vt` and Apple native-linker support improve cross-platform library builds. Wayland hotkey handling is polished; FreeBSD builds track Zig 0.16.

## 2026-03-09

**v1.3.0** ships. The release cycle adds search-selection highlighting, configurable selection word boundaries, an AFL++ fuzz harness for `libghostty-vt`, Android as a `libghostty-vt` build target, and expanded i18n coverage across many locales.

## 2025-10-01

**Zig 0.15** lands across the tree — GTK, macOS, Flatpak, snap, and `libghostty-vt` builds. `libghostty-vt` matures rapidly: C APIs for key encoding, SGR parsing, paste utilities, freestanding WASM builds, hosted Doxygen docs, and multi-target CI. Selection APIs expand (formatting, word/line helpers, tracked grid refs). FreeBSD CI is re-enabled on 15.0.

## 2025-09-21

**libghostty-vt** is extracted as a first-class shared library with pkg-config, cross-target CI, and a documented C API — the embeddable terminal-state layer Mitchell Hashimoto previewed in ["libghostty is coming"](https://mitchellh.com/writing/libghostty-is-coming). **v1.2.0** tags shortly after.

## 2025-06-12

**FreeBSD** joins macOS, Linux, and Windows as a supported platform, with GTK builds, fontconfig/terminfo path fixes, and CI on Namespace/Firecracker infrastructure.

## 2025-03-11

**Zig 0.14** upgrade. **v1.1.x** cycle brings first-class **Wayland** support (layer-shell quick terminal, KDE Plasma background blur, server-side decorations), a global **i18n** system with gettext extraction from Zig and GTK sources, and German/Chinese initial translations.

## 2024-12-26

**v1.0.0** — Ghostty declares stable. Years of private and public-beta development culminate in tagged releases with signed source tarballs (`release.files.ghostty.org`), Sparkle auto-update on macOS, release-channel awareness, and DMG generation. The public website moves to `ghostty.org`; the in-repo website directory is removed in favor of the external docs site.

## 2024-09 → 2024-12

The run-up to 1.0: **Quick Terminal** (slide-down overlay) ships on macOS. Scrollback **search** matures via sliding-window `PageList` search. **libghostty** C API consolidation accelerates (unified action dispatch, color structs, config reload). Metal renderer gets dirty-tracking, display-link frame pacing, and shaping caches. Inspector, Kitty graphics, and split/tab windowing reach production quality.

## 2024-01 → 2024-08

**libghostty** emerges as an explicit C-ABI library for macOS and Linux CI builds. **Zig 0.12 → 0.13** migrations land. Windows builds stabilize (WTF-8 paths, rc files, termio fixes). Metal renderer is rewritten around per-cell content tracking and triple-buffering experiments. Flatpak and snap packaging mature.

## 2023-10 → 2023-12

Public beta era: a **SwiftUI/AppKit** macOS rewrite (TerminalManager, native tabs/splits) replaces earlier AppKit scaffolding. The **terminal inspector** (ImGui-based debugging UI) ships on macOS and GTK. **Sparkle** auto-update and GitHub release workflows are wired; friend-invite beta testers transition toward MIT-licensed public distribution. Kitty graphics protocol reaches Metal rendering. **Windows** port begins (GLFW backend, cross-compile CI).

## 2023-02 → 2023-09

Cross-platform expansion: **GTK** application runtime (tabs, splits, Flatpak builds, Adwaita). **Shell integration** injection (fish, then bash/zsh). Font system hardening (CoreText discovery, fallback chains, presentation checks). **Kitty graphics** protocol implementation begins (August marathon). Activity surges from ~100 commits/month to 300–450/month as the feature set broadens.

## 2022-11 → 2023-01

Platform depth on macOS: **Metal renderer** replaces OpenGL (October–November 2022) with ubershader glyph rendering, HiDPI, cursor/underline styles. **IO thread** architecture lands. Native macOS tabbing, release-tip CI, and signed bundle distribution. Early **Swift** build experiments foreshadow the later AppKit/SwiftUI app.

## 2022-03 → 2022-10

Genesis: initial commit (March 29, 2022). OpenGL renderer, pure-Zig font atlas, VT100-style state-table parser (April). CSI/OSC/SGR parsing, scrolling regions, UTF-8, resizing, color palettes, and keybindings follow through summer. OpenGL text rendering connects to live terminal state in April. macOS compilation and Nix dev environment established by mid-year.
```
