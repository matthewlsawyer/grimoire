## HISTORY.md

```markdown
# History

Ghostty is a fast, native, feature-rich terminal emulator and embeddable terminal library (`libghostty`), written primarily in Zig with platform-native shells on macOS (SwiftUI/Metal) and Linux (GTK/OpenGL). This file is a temporal ledger of how the project got here — story beats, turning points, and provenance — distilled from git history and project docs.

## Story

A two-year solo incubation became a community-driven 1.0, then a platform for extracting battle-tested terminal emulation into `libghostty-vt` while the GUI keeps shipping.

### Origins

Mitchell Hashimoto started Ghostty in March 2022 (`f8b000044`) to build the terminal emulator he wanted: fast, native, and uncompromising on modern features. Early weeks bounced through GLFW, WebGPU/Dawn, and raylib before settling on OpenGL for cross-platform rendering and a Zig core for terminal state, parsing, and I/O. By late 2022 the macOS Metal renderer was drawing glyphs (`178418834`), VT emulation tables were in place, and a private release pipeline (`2d3126ffb`) was taking shape — all before the project was public.

## 2026-07-30

The tree at `tip` (`4d605bf0`) reflects a project in library-hardening mode. Zig 0.16 landed (`e8525c0fd`, merged `2026-07-22`) with follow-on fixes across global state, Metal buffers, and FreeBSD i18n builds. `libghostty` gained runtime scrollback limits (`f4c68d65e`), DECRQSS handling, and PageList builder APIs for lower-level memory control. On Linux, Wayland global hotkeys arrived via `vicinae-hotkey-v1` (`88bd4fdce`), and work began on a binary snapshot API (`4d605bf0`). Five roadmap steps are done; Ghostty-only control sequences remain the open frontier.

## 2026-03-09

**v1.3.0** shipped (`Bump version to 1.3.0`). The release cycle included `libghostty-vt` parser fuzzing with AFL++ (`2026-03-01`), Android CI targets, and an initial C API for terminal formatting (`2026-03-14`). i18n coverage expanded (e.g. Lithuanian for v1.3).

## 2025-09-22

**`libghostty-vt` extraction** (`ghostty-vt Zig Module`, `#8840`) — the biggest architectural bet since the GTK port. Terminal sequence parsing and state management became a standalone C/Zig library with pkg-config, SONAME versioning (`2025-09-30`), OSC parsing APIs, and freestanding WASM builds (`2025-10-21`). The GUI app and third-party embedders now share one proven VT core; `libghostty` (full surface/windowing) continues alongside it.

## 2025-03-13

**Zig 0.14** (`#6699`) forced a broad toolchain migration: `mach-glfw` replaced by `pkg/glfw` (`#6708`), `build.zig` refactored for Wayland protocols via `build.zig.zon` (`#4797`). **Cross-platform i18n** groundwork landed (`#6619`) — gettext/libintl on GTK and macOS, with localization teams in CODEOWNERS. Norwegian, Indonesian, and more `.po` files followed.

## 2025-01-02

**Wayland on Linux** entered the build (`build: add wayland`), with KDE Plasma background blur (`#4403`) and later `ext-background-effect-v1` (`2026-03-18`). GTK remained the Linux shell; X11 was still preferred on GTK 4.14 (`#2893`, `2024-12-05`) while Wayland parity caught up through 2026.

## 2024-12-26

**v1.0.0** (`build.zig: v1.0.0`) — stable release after ~1,000 days of development. Preceded by macOS DMG release workflows (`#3047`), a colorized app icon, and README updates for the launch. README now states Ghostty is stable and used by millions daily; six of seven roadmap steps marked complete.

## 2024-06-01

**`ghostty-org`** — the repository moved under community organization (`#1812`). Contribution velocity jumped: hundreds of merged PRs through summer 2024 covering GTK polish, Sparkle updates, Kitty graphics (`#1924`), tmux control mode (`#1946`), and Zig 0.13 (`#1879`). The private Mitchell Hashimoto repo became an open, multi-maintainer project.

## 2024-01-18

**`libghostty` cross-platform** — Linux builds (`#1324`) and Windows support (`#1326`) landed, with unified action dispatch on macOS (`#2305`, `2024-09-27`). The embeddable-library roadmap (step 5) moved from macOS-only toward the C API surface documented today.

## 2023-02-23

**GTK/Linux app** — a working GTK backend in a week (`gtk: render!`, merged `#75`). Tabs, clipboard, and Flatpak packaging (`#79`) followed; `release-tip` CI (`2022-11-17`) began shipping unsigned then signed macOS bundles. macOS splits arrived (`2023-03-07`); Metal replaced OpenGL on Apple hosts for production rendering.

## 2022-10-30

**Metal renderer** — native macOS glyph rendering (`metal: glyphs show up`, `178418834`) ended dependence on OpenGL for the primary platform. OpenGL remained the Linux path. Multi-threaded read/write/render architecture and SIMD parser optimizations (described in README) matured through 2023–2024.

## 2022-03-29

**Genesis** (`f8b000044`, Initial). First window on screen (`cc4d37804`), OpenGL triangle (`dc3d2d65d`), VT emulation table (`2022-04-18`), PTY basics (`2022-04-15`). The name and ambition were set early; everything since has been closing the gap between prototype and the README's promise of speed, features, and native UX.
```
