## HISTORY.md

```markdown
# History

Build Awesome (Eleventy) is a JavaScript static site generator; this sidecar records forge provenance for the repository.

<!-- marker: 17210371 -->

## Story

### Origins

November 2017: Eleventy began as a minimal Jekyll alternative in JavaScript - template directory in, HTML out. Early commits added async rendering, Liquid, CLI flags, and subfolder templates.

### Architecture

A `src/` core drives discovery, data cascade, and multi-engine template compilation. Plugins extend config downstream. v3 stabilized Nunjucks, Markdown, WebC, and a large test matrix (ava, Node test runner, Vitest browser mode). v4 alpha restructures around workspace packages (`packages/build-awesome`, `packages/browser`), a new bundle plugin, and Build Awesome branding while keeping `@11ty/eleventy` on npm.

### Refactors

2017 -> 2019: plugin system, pagination, Jekyll-compatible includes, and rapid 0.x releases. 2020 -> 2025: v1, v2, and v3 major lines, performance work, and ecosystem growth. 2026: Build Awesome naming, v4.0.0-alpha releases, async Nunjucks migration, and repository move to `11ty/buildawesome`.
```
