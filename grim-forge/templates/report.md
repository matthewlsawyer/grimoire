# Report

## Structure

````markdown
# Grim Forge: {Project Name}

```text
{workspace}/HISTORY.md
╞══════════════════◆
│
├─≣ 2026-07-29
│  └─ {One-liner distillation of entry.}
└─≣ ...
   └─ ...
```

{One short paragraph about the changes made to ledger files.}
````

## Rules

- **Show the delta**. Capture only what was written or appended this run. If this is the first run show the full tree.

## Style Guide

- Hierarchy glyphs: `│`, `├`, `└`, `─`.
- Ledger trunk glyphs: `├─≣`, `└─≣`, `─≣`.
- Divider glyph: `╞══════════════════◆`.
- Indent each level, continue ancestors with `│`.
- `├─` for non-final sibling;
- `└─` for final sibling.
